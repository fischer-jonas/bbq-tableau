# \# Bochum BBQ / Grassland Fire Index Dashboard

# 

# This project visualizes the \*\*Grassland Fire Index for Bochum\*\* based on open environmental data and presents the results in an interactive Tableau dashboard.

# 

# \---

# 

# \## Dashboard

# 

# The dashboard is publicly available here:

# 

# https://public.tableau.com/app/profile/jonas.fischer7961/viz/BochumBBQ/Dashboard1?publish=yes

# 

# Created with Tableau Public.

# 

# \---

# 

# \## Data Source

# 

# The data originates from the Open Data portal of the City of Bochum:

# 

# \- Grassland Fire Index time series

# \- Format: CSV

# \- Source: GitLab Open Data Repository of the City of Bochum

# 

# Example URL:

# https://gitlab.opencode.de/StadtBochum/open-data/umwelt-graslandfeuerindex/-/raw/main/data/bochum\_graslandfeuerindex\_summary.csv

# 

# \---

# 

# \## Project Structure

# 

# The project consists of three main components:

# 

# \### 1. Data Source

# \- Open data CSV provided by the City of Bochum

# \- regularly updated time series data

# 

# \### 2. Data Processing (optional)

# \- Python script for automated CSV download

# \- ensures a stable local data source for Tableau

# 

# \### 3. Visualization

# \- Tableau dashboard

# \- analysis of time trends and extreme values

# \- focus on fire risk (grassland fire index)

#
